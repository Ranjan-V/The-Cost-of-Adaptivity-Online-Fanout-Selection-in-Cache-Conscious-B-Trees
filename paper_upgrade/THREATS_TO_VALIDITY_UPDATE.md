# Threats to validity

The 5M-key tree and generated operation vector may strain a 16 GB laptop. Check working set and exclude swapping runs with a documented rule. The i5-12500H is hybrid; scheduler placement, turbo and thermals can add variance. Use randomized order, paired seeds, stable power, and report CV. Kaggle sessions can use different CPUs; split machine groups and compare normalized patterns only. V2 changes monitor, controller, and rebuild jointly, so package-level throughput alone does not identify one cause. Adjacent ablation differences may be noisy; report paired intervals. The original B+ tree's concurrent code and memory reclamation need a separate correctness review; the present adaptation study is single-threaded. The zero-cost static envelope is retrospective and optimistic. The evaluation attributes costs through controlled software ablations and does not claim a hardware-level cache-miss mechanism. Existing Wikipedia data provenance should be checked before “real trace” claims.
